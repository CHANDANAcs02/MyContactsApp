# MyContacts App

A Java console application developed using Object-Oriented Programming concepts and Design Patterns.

## Features

- User Registration
- User Authentication
- Profile Management
- Contact Management
- View Contact Details
- Edit Contacts
- Delete Contacts
- Bulk Operations
- Search Contacts
- Advanced Filtering
- Manage Tags
- Apply Tags

## Technologies

- Java
- IntelliJ IDEA
- Git & GitHub
